1. 개요

SyntaxOrigin Multi Tools는 파일 변환(비디오, 오디오, 이미지, 오피스 문서, PDF)과 수천 개 플랫폼에서의 미디어 다운로드를 위한 데스크톱 애플리케이션으로, 빠른 네이티브 창에 담겨 있습니다. Wails 프레임워크로 제작되었습니다. 사용자 인터페이스는 일반적인 HTML/CSS/JS 페이지이며, 무거운 모든 작업(FFmpeg, yt-dlp, LibreOffice, poppler)은 Go 백엔드에서 실행됩니다. 21개 언어를 지원하며 Windows와 Linux에서 작동합니다.

2. 기능

  • 비디오, 오디오, 이미지, 문서 파일을 형식 간에 변환합니다.
  • yt-dlp가 지원하는 플랫폼에서 비디오 또는 MP3 음악을 다운로드합니다.
  • FFmpeg와 yt-dlp 원클릭 설치; LibreOffice와 poppler 자동 감지.
  • 21개 언어: 운영체제 설정을 자동으로 사용하며 언제든지 전환할 수 있고, 아랍어·우르두어·페르시아어는 RTL 레이아웃을 사용합니다.
  • 진행률 막대와 단계별 상태 메시지를 갖춘 실시간 작업 목록.
  • 외부 프런트엔드 라이브러리 없음 — 빠르고 어두운 테마의 데스크톱 UI.

종류입력출력

오디오mp3, wav, flac, aac, oggmp3, wav, flac, aac, ogg

참고: 문서 변환(PDF ↔ DOCX, PDF → 이미지/텍스트)에는 시스템에 LibreOffice 및/또는 poppler가 설치되어 있어야 합니다. 이들은 자동으로 감지되지만 앱에 번들로 포함되지 않습니다 — 도구 탭을 참조하세요.

4. 시스템 요구 사항

런타임 도구

도구용도
FFmpeg모든 비디오/오디오/이미지 변환; 최고 품질 병합 다운로드

FFmpeg와 yt-dlp는 애플리케이션 내부에서 한 번의 클릭으로 설치할 수 있습니다. LibreOffice와 poppler는 사용자가 직접 설치해야 합니다(링크는 도구 탭에 표시됩니다).

5. 설치 (Windows / Linux)

  1. 플랫폼에 맞는 바이너리를 다운로드하여 실행하거나(릴리스 파일 참조), 또는 직접 빌드합니다 — 소스에서 빌드를 참조하세요.
  2. 첫 실행 시 앱이 운영체제의 언어를 자동으로 선택합니다. 감지할 수 없으면 영어로 대체됩니다.
  3. 도구 탭을 엽니다. 누락된 것으로 표시된 도구에는 설치 버튼이 나타납니다. 먼저 FFmpeg와 yt-dlp를 설치하세요.
  4. 이제 변환과 다운로드를 시작할 준비가 되었습니다.
Windows: 기본 빌드는 서명되지 않았으므로 SmartScreen이 "알 수 없는 게시자" 경고를 표시할 수 있습니다. 추가 정보 → 실행을 선택하세요. 일부 바이러스 백신/프록시 도구는 바이너리 다운로드를 차단할 수 있습니다. 앱과 해당 bin 폴더에 예외를 추가하세요.

6. 언어 선택

  • 시작 시 운영체제의 언어가 자동으로 사용됩니다(대체: 영어).
  • 언어 선택기는 창의 오른쪽 상단에 있습니다. 언어를 선택하면 실행 중인 작업을 포함한 전체 인터페이스가 즉시 번역됩니다.
  • 직접 선택한 언어는 기억되어 다음 시작 시 우선 적용됩니다.
  • 아랍어, 우르두어, 페르시아어는 자동으로 오른쪽에서 왼쪽(RTL) 레이아웃을 사용합니다.

7. 도구 탭

도구앱 내 설치 가능비고
FFmpeg예Windows: BtbN GPL 빌드; Linux: johnvansickle 정적 빌드(약 120 MB)
yt-dlp예플랫폼에 맞는 바이너리가 다운로드됩니다
LibreOffice아니요libreoffice.org에서 설치
poppler아니요poppler.freedesktop.org에서 설치

파일은 사용자별 구성 폴더의 SyntaxOrigin Multi Tools\bin에 저장됩니다(Windows: %APPDATA%. Linux: $XDG_CONFIG_HOME 또는 ~/.config).

8. 변환 가이드

  1. 변환 탭으로 이동합니다.
  2. 종류(비디오 / 오디오 / 이미지 / 문서)를 선택합니다.
  3. 입력 파일 선택을 클릭하고 파일을 고릅니다(지원 형식은 자동으로 필터링됩니다).
  4. 대상 형식을 선택합니다. 비디오/오디오의 경우 선택적으로 비트레이트를 설정할 수 있으며, 비디오의 경우 너비 × 높이도 조절할 수 있습니다.
  5. 출력 위치를 선택하고(파일 이름이 자동으로 제안됨) 변환을 누릅니다.
  6. 작업은 하단(작업)에 실시간 진행률 막대와 함께 표시됩니다.

9. 다운로드 가이드

  1. 다운로드 탭으로 이동합니다.
  2. 비디오/음악 URL을 붙여넣습니다.
  3. 모드를 선택합니다: 비디오 또는 음악 (MP3).
  4. 비디오의 품질을 선택합니다: 최고, 2160p, 1440p, 1080p, 720p, 480p. MP3의 경우 최상의 오디오 스트림이 자동으로 사용됩니다.
  5. 필요에 따라 다운로드 폴더를 변경합니다(기본값은 Downloads 폴더).
  6. 다운로드를 누릅니다. 출력 파일 이름은 Title [id].mp4 또는 Title [id].mp3입니다.
팁: FFmpeg가 설치되지 않은 경우 비디오 다운로드는 단일 스트림 파일로 대체됩니다(소리가 없거나 덜 일반적인 컨테이너가 될 수 있음). 깔끔하게 병합된 MP4 파일을 얻으려면 도구 탭에서 FFmpeg를 설치하세요.

10. 작업 패널

  • 모든 작업(변환, 다운로드, 설치)은 작업으로 백그라운드에서 실행됩니다.
  • 작업은 진행률 백분율과 짧은 상태 메시지와 함께 창 하단에 표시됩니다.
  • 성공하면 생성된 파일 경로가 표시됩니다. 버튼을 누르면 파일 관리자에서 폴더가 열리거나 파일이 선택됩니다.

11. 문제 해결

  • "yt-dlp not found" / 다운로드 오류 → 도구 탭에서 yt-dlp를 설치하세요.
  • 다운로드한 비디오에 소리가 없거나 이상한 컨테이너 형식인 경우 → FFmpeg를 설치하여 스트림을 병합하세요.
  • DOCX → PDF가 아무것도 만들지 못함 → LibreOffice를 설치하세요.
  • PDF → 이미지/텍스트가 아무것도 만들지 못함 → poppler를 설치하세요.
  • 다운로드가 멈추거나 진행률이 동결됨 → 플랫폼이 yt-dlp나 연결을 차단하고 있을 수 있습니다. yt-dlp를 업데이트(도구에서 재설치)한 후 다시 시도하세요.
  • 도구 설치 실패 → 인터넷 연결/프록시/방화벽을 확인하세요. 다운로드는 GitHub Releases 또는 johnvansickle.com에서 이루어집니다.

12. 소스에서 빌드

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux에서는 먼저 WebKit2GTK/GTK3 개발 패키지가 필요합니다:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev는 핫 리로드 개발 모드에서 앱을 실행합니다. 이 명령은 frontend/dist와 frontend/wailsjs를 자동으로 다시 생성합니다. Linux CI 파이프라인(AMD64 + ARM64)은 .github/workflows 아래에 제공됩니다.

13. 프로젝트 구조

├── app.go                 # Wails bindings: jobs, convert, download, dialogs
├── i18n.go                # Backend strings + system-language detection
├── main.go                # App entry point (wails.Run)
├── internal/
│   ├── converter/         # audio, video, image, document converters

│   ├── tools/             # tool detection + one-click installers
│   └── ytdlp/             # yt-dlp wrapper (progress parsing, formats)
├── frontend/
│   └── src/               # vanilla-JS UI (index.html, app.js, i18n.js, style.css)
├── wails.json
├── README.md
└── wiki/<language>/       # this documentation (HTML)
