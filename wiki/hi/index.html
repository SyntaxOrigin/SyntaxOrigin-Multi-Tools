1. अवलोकन

SyntaxOrigin Multi Tools एक डेस्कटॉप एप्लिकेशन है जो फ़ाइलों को कनवर्ट करने (वीडियो, ऑडियो, छवि, ऑफ़िस और PDF) और हजारों प्लेटफ़ॉर्मों से मीडिया डाउनलोड करने के लिए है, जो एक तेज़ नेटिव विंडो में उपलब्ध है। इसे Wails फ्रेमवर्क के साथ बनाया गया है: यूज़र इंटरफ़ेस एक सामान्य HTML/CSS/JS पेज है, जबकि सभी भारी कार्य (FFmpeg, yt-dlp, LibreOffice, poppler) एक Go बैकएंड में चलते हैं। यह 21 भाषाओं का समर्थन करता है और Windows तथा Linux पर कार्य करता है।

2. विशेषताएँ

  • वीडियो, ऑडियो, छवि और दस्तावेज़ फ़ाइलों को एक प्रारूप से दूसरे प्रारूप में कनवर्ट करें।
  • yt-dlp द्वारा समर्थित प्लेटफ़ॉर्मों से वीडियो या MP3 संगीत डाउनलोड करें।
  • FFmpeg और yt-dlp की एक-क्लिक स्थापना; LibreOffice और poppler का स्वचालित पता लगाना।
  • 21 भाषाएँ: ऑपरेटिंग सिस्टम से स्वचालित रूप से ली जाती हैं, किसी भी समय बदली जा सकती हैं, अरबी, उर्दू और फ़ारसी के लिए RTL लेआउट के साथ।
  • प्रगति पट्टियों और चरण-दर-चरण स्थिति संदेशों वाली लाइव कार्य सूची।
  • कोई बाहरी फ्रंटएंड लाइब्रेरी नहीं — एक तेज़, डार्क डेस्कटॉप UI।

5. स्थापना (Windows / Linux)

  1. अपने प्लेटफ़ॉर्म के लिए बायनरी डाउनलोड करें और उसे चलाएँ (रिलीज़ फ़ाइलें देखें), या इसे स्वयं बनाएँ — स्रोत से बनाना देखें।
  2. पहली बार लॉन्च पर, ऐप ऑपरेटिंग सिस्टम की भाषा का स्वचालित रूप से चयन करता है। यदि वह पहचान न पाए, तो वह अंग्रेज़ी पर वापस आती है।
  3. Tools टैब खोलें। जो उपकरण अनुपलब्ध हैं, उन पर Install (स्थापित करें) बटन दिखता है। पहले FFmpeg और yt-dlp स्थापित करें।
  4. अब आप कनवर्ट और डाउनलोड करने के लिए तैयार हैं।
Windows: चूँकि डिफ़ॉल्ट बिल्ड हस्ताक्षरित नहीं है, SmartScreen "अज्ञात प्रकाशक" (unknown publisher) की चेतावनी दे सकता है। अधिक जानकारी → फिर भी चलाएँ (More info → Run anyway) चुनें। कुछ एंटीवायरस/प्रॉक्सी उपकरण बायनरी डाउनलोड को ब्लॉक कर सकते हैं; ऐप और उसके bin फ़ोल्डर के लिए अपवाद जोड़ें।

6. भाषा चयन

  • स्टार्टअप पर ऑपरेटिंग सिस्टम की भाषा का स्वचालित रूप से उपयोग होता है (फ़ॉलबैक: अंग्रेज़ी)।
  • भाषा चयनकर्ता विंडो के ऊपर-दाईं ओर होता है। कोई भाषा चुनने पर पूरा इंटरफ़ेस तुरंत अनुवादित हो जाता है (चल रहे कार्यों सहित)।
  • आपकी मैन्युअल पसंद याद रखी जाती है और अगली बार लॉन्च पर उसे प्राथमिकता मिलती है।
  • अरबी, उर्दू और फ़ारसी स्वचालित रूप से दाएँ-से-बाएँ लेआउट का उपयोग करती हैं।

7. Tools टैब

उपकरणऐप में स्थापना योग्यटिप्पणियाँ

फ़ाइलें प्रति-उपयोगकर्ता कॉन्फ़िग फ़ोल्डर में SyntaxOrigin Multi Tools\bin के अंतर्गत संग्रहीत होती हैं (Windows: %APPDATA%; Linux: $XDG_CONFIG_HOME या ~/.config).

8. कनवर्ट करने की मार्गदर्शिका

  1. Convert (कनवर्ट करें) टैब पर जाएँ।
  2. प्रकार (वीडियो / ऑडियो / छवि / दस्तावेज़) चुनें।
  3. इनपुट चुनें (Select input) पर क्लिक करें और फ़ाइल चुनें (समर्थित प्रारूप स्वचालित रूप से फ़िल्टर होते हैं)।
  4. लक्ष्य प्रारूप चुनें। वीडियो/ऑडियो के लिए आप वैकल्पिक रूप से बिटरेट सेट कर सकते हैं; वीडियो के लिए आप चौड़ाई × ऊँचाई भी बदल सकते हैं।
  5. आउटपुट स्थान चुनें (फ़ाइल नाम स्वचालित रूप से सुझाया जाता है) और Convert (कनवर्ट करें) दबाएँ।
  6. कार्य नीचे (Jobs) में लाइव प्रगति पट्टी के साथ दिखाई देता है।

9. डाउनलोड मार्गदर्शिका

  1. Download (डाउनलोड) टैब पर जाएँ।
  2. वीडियो/संगीत का URL पेस्ट करें।
  3. मोड चुनें: वीडियो या संगीत (MP3)।
  4. वीडियो के लिए गुणवत्ता चुनें: सर्वोत्तम, 2160p, 1440p, 1080p, 720p, 480p। MP3 के लिए सर्वोत्तम ऑडियो स्ट्रीम स्वचालित रूप से उपयोग होती है।
  5. वैकल्पिक रूप से डाउनलोड फ़ोल्डर बदलें (डिफ़ॉल्ट रूप से आपके Downloads फ़ोल्डर का उपयोग होता है)।
  6. Download (डाउनलोड करें) दबाएँ। आउटपुट का नाम Title [id].mp4 या Title [id].mp3 होता है।
टिप: यदि FFmpeg स्थापित नहीं है, तो वीडियो डाउनलोड एकल-स्ट्रीम फ़ाइलों में बदल जाते हैं (वीडियो में ध्वनि नहीं हो सकती या कम सामान्य कंटेनर इस्तेमाल हो सकता है)। साफ़ मर्ज किए गए MP4 फ़ाइलों के लिए Tools टैब से FFmpeg स्थापित करें।

10. Jobs पैनल

  • हर कार्य (कनवर्ट, डाउनलोड, स्थापना) पृष्ठभूमि में एक job (कार्य) के रूप में चलता है।
  • कार्य विंडो के नीचे प्रगति प्रतिशत और संक्षिप्त स्थिति संदेश के साथ सूचीबद्ध होते हैं।
  • सफलता पर उत्पादित फ़ाइल का पथ दिखाया जाता है; बटन फ़ोल्डर खोलता है / फ़ाइल मैनेजर में फ़ाइल का चयन करता है।

11. समस्या समाधान

  • "yt-dlp नहीं मिला" / डाउनलोड त्रुटि → Tools टैब से yt-dlp स्थापित करें।
  • डाउनलोड किए गए वीडियो में ध्वनि नहीं है या अजीब कंटेनर है → FFmpeg स्थापित करें ताकि स्ट्रीम मर्ज हो जाएँ।
  • DOCX → PDF से कुछ नहीं बनता → LibreOffice स्थापित करें।
  • PDF → छवि/पाठ से कुछ नहीं बनता → poppler स्थापित करें।
  • डाउनलोड रुक जाता है / प्रगति जम जाती है → प्लेटफ़ॉर्म yt-dlp या कनेक्शन को ब्लॉक कर रहा हो सकता है; yt-dlp अपडेट करें (Tools से दोबारा स्थापित करें) और फिर से प्रयास करें।
  • उपकरण स्थापना विफल होती है → इंटरनेट कनेक्टिविटी / प्रॉक्सी / फ़ायरवॉल की जाँच करें; डाउनलोड GitHub Releases या johnvansickle.com से आता है।

12. स्रोत से बनाना

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux को पहले WebKit2GTK/GTK3 विकास पैकेजों की आवश्यकता होती है:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev ऐप को हॉट-रिलोड डेवलपमेंट मोड में लॉन्च करता है। यह कमांड frontend/dist और frontend/wailsjs को स्वचालित रूप से पुनर्जनित करता है। .github/workflows के अंतर्गत एक Linux CI पाइपलाइन (AMD64 + ARM64) उपलब्ध है।
