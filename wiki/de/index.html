1. Überblick

SyntaxOrigin Multi Tools ist eine Desktop-Anwendung zum Konvertieren von Dateien (Video, Audio, Bild, Office und PDF) und zum Herunterladen von Medien von Tausenden von Plattformen, verpackt in ein schnelles natives Fenster. Sie basiert auf dem Wails-Framework: Die Benutzeroberfläche ist eine normale HTML/CSS/JS-Seite, während die gesamte rechenintensive Arbeit (FFmpeg, yt-dlp, LibreOffice, poppler) in einem Go-Backend läuft. Die Anwendung unterstützt 21 Sprachen und funktioniert unter Windows und Linux.

2. Funktionen

  • Konvertieren Sie Video-, Audio-, Bild- und Dokument-Dateien zwischen den Formaten.
  • Laden Sie Videos oder MP3-Musik von Plattformen herunter, die von yt-dlp unterstützt werden.
  • Ein-Klick-Installation von FFmpeg und yt-dlp; automatische Erkennung von LibreOffice und poppler.
  • 21 Sprachen: wird automatisch aus dem Betriebssystem übernommen, jederzeit umschaltbar, mit RTL-Layout für Arabisch, Urdu und Persisch.
  • Live-Jobliste mit Fortschrittsbalken und schrittweisen Statusmeldungen.
  • Keine externen Frontend-Bibliotheken — eine schnelle, dunkle Desktop-Oberfläche.

5. Installation (Windows / Linux)

  1. Laden Sie die Binärdatei für Ihre Plattform herunter und führen Sie sie aus (siehe die Releasetabellen), oder erstellen Sie sie selbst — siehe Erstellen aus dem Quellcode.
  2. Beim ersten Start wählt die Anwendung automatisch die Sprache des Betriebssystems. Wenn keine erkannt werden kann, wird Englisch verwendet.
  3. Öffnen Sie die Registerkarte Tools. Als fehlend markierte Werkzeuge zeigen eine Schaltfläche Installieren. Installieren Sie zuerst FFmpeg und yt-dlp.
  4. Sie sind bereit zum Konvertieren und Herunterladen.
Windows: Da der Standard-Build nicht signiert ist, kann SmartScreen vor einem „unbekannten Herausgeber" warnen. Wählen Sie Weitere Informationen → Trotzdem ausführen. Einige Antiviren-/Proxyprogramme können Binärdatei-Downloads blockieren; fügen Sie eine Ausnahme für die Anwendung und ihren bin-Ordner hinzu.

6. Sprachauswahl

  • Beim Start wird automatisch die Sprache des Betriebssystems verwendet (Fallback: Englisch).
  • Der Sprachauswahl-Schalter befindet sich oben rechts im Fenster. Die Auswahl einer Sprache übersetzt sofort die gesamte Oberfläche (einschließlich laufender Jobs).
  • Ihre manuelle Auswahl wird gespeichert und hat beim nächsten Start Vorrang.
  • Arabisch, Urdu und Persisch verwenden automatisch ein rechts-nach-links-Layout.

8. Anleitung zur Konvertierung

  1. Gehen Sie zur Registerkarte Konvertieren.
  2. Wählen Sie die Art (Video / Audio / Bild / Dokument).
  3. Klicken Sie auf Eingabedatei auswählen und wählen Sie die Datei (unterstützte Formate werden automatisch gefiltert).
  4. Wählen Sie das Zielformat. Bei Video/Audio können Sie optional eine Bitrate festlegen; bei Video können Sie auch die Breite × Höhe skalieren.
  5. Wählen Sie den Ablageort (ein Dateiname wird automatisch vorgeschlagen) und drücken Sie Konvertieren.
  6. Der Job erscheint unten (Jobs) mit einem Live-Fortschrittsbalken.

9. Anleitung zum Herunterladen

  1. Gehen Sie zur Registerkarte Herunterladen.
  2. Fügen Sie die Video-/Musik-URL ein.
  3. Wählen Sie den Modus: Video oder Musik (MP3).
  4. Wählen Sie die Qualität für Videos: Best, 2160p, 1440p, 1080p, 720p, 480p. Bei MP3 wird automatisch der beste Audiostream verwendet.
  5. Ändern Sie optional den Download-Ordner (Standard ist Ihr Downloads-Ordner).
  6. Drücken Sie Herunterladen. Die Ausgabe wird als Title [id].mp4 oder Title [id].mp3 benannt.
Tipp: Wenn FFmpeg nicht installiert ist, werden Video-Downloads auf Single-Stream-Dateien zurückgegriffen (das Video kann ohne Ton sein oder einen weniger verbreiteten Container verwenden). Installieren Sie FFmpeg über die Registerkarte Tools für saubere, zusammengeführte MP4-Dateien.

10. Bedienfeld Jobs

  • Jede Aktion (Konvertieren, Herunterladen, Installieren) läuft im Hintergrund als Job.
  • Jobs werden unten im Fenster mit Fortschrittsprozentsatz und einer kurzen Statusmeldung aufgelistet.
  • Bei Erfolg wird der Pfad der erzeugten Datei angezeigt; der Knopf öffnet den Ordner / wählt die Datei im Dateimanager aus.

11. Fehlerbehebung

  • „yt-dlp nicht gefunden" / Download-Fehler → installieren Sie yt-dlp über die Registerkarte Tools.
  • Hergeladenes Video ohne Ton oder mit ungewöhnlichem Container → installieren Sie FFmpeg, damit die Streams zusammengeführt werden.
  • DOCX → PDF erzeugt nichts → installieren Sie LibreOffice.
  • PDF → Bild/Text erzeugt nichts → installieren Sie poppler.
  • Download bleibt stehen / Fortschritt eingefroren → die Plattform blockiert möglicherweise yt-dlp oder die Verbindung; aktualisieren Sie yt-dlp (neuinstallieren über Tools) und versuchen Sie es erneut.
  • Werkzeuginstallation schlägt fehl → überprüfen Sie die Internetverbindung / den Proxy / die Firewall; der Download kommt von den GitHub Releases oder von johnvansickle.com.

12. Erstellen aus dem Quellcode

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Unter Linux werden zuerst die WebKit2GTK/GTK3-Entwicklungspakete benötigt:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev startet die Anwendung im Hot-Reload-Entwicklungsmodus. Der Befehl generiert frontend/dist und frontend/wailsjs automatisch neu. Eine Linux-CI-Pipeline (AMD64 + ARM64) ist unter .github/workflows enthalten.
