1. Resumen

SyntaxOrigin Multi Tools es una aplicación de escritorio para convertir archivos (vídeo, audio, imagen, documentos de oficina y PDF) y descargar medios de miles de plataformas, envuelta en una ventana nativa rápida. Está construida con el framework Wails: la interfaz de usuario es una página HTML/CSS/JS normal, mientras que todo el trabajo pesado (FFmpeg, yt-dlp, LibreOffice, poppler) se ejecuta en un backend en Go. Es compatible con 21 idiomas y funciona en Windows y Linux.

2. Funciones

  • Convertir archivos de vídeo, audio, imagen y documento entre formatos.
  • Descargar vídeos o música MP3 de las plataformas compatibles con yt-dlp.
  • Instalación con un clic de FFmpeg y yt-dlp; detección automática de LibreOffice y poppler.
  • 21 idiomas: se toma automáticamente del sistema operativo, se puede cambiar en cualquier momento y con diseño RTL para árabe, urdu y persa.
  • Lista de trabajos en vivo con barras de progreso y mensajes de estado paso a paso.
  • Sin librerías frontend externas — una interfaz de escritorio oscura y rápida.

5. Instalación (Windows / Linux)

  1. Descargue el binario para su plataforma y ejecútelo (consulte los archivos de la versión), o compílelo usted mismo — consulte Compilación desde el código fuente.
  2. En el primer inicio, la aplicación selecciona automáticamente el idioma del sistema operativo. Si no puede detectarlo, recurre al inglés.
  3. Abra la pestaña Herramientas. Las herramientas marcadas como faltantes muestran un botón Instalar. Instale primero FFmpeg y yt-dlp.
  4. Ya está listo para convertir y descargar.
Windows: como la compilación predeterminada no está firmada, es posible que SmartScreen advierta sobre un «editor desconocido». Elija Más información → Ejecutar de todos modos. Algunas herramientas antivirus/proxy pueden bloquear las descargas de binarios; añada una excepción para la aplicación y su carpeta bin.

6. Selección de idioma

  • Al iniciar, se usa automáticamente el idioma del sistema operativo (alternativa: inglés).
  • El selector de idioma está en la esquina superior derecha de la ventana. Elegir un idioma traduce inmediatamente toda la interfaz (incluidos los trabajos en curso).
  • Su elección manual se recuerda y tiene prioridad en el siguiente inicio.
  • El árabe, el urdu y el persa usan automáticamente un diseño de derecha a izquierda.

8. Guía de conversión

  1. Vaya a la pestaña Convertir.
  2. Elija el Tipo (Vídeo / Audio / Imagen / Documento).
  3. Haga clic en Seleccionar entrada y elija el archivo (los formatos compatibles se filtran automáticamente).
  4. Elija el formato de destino. Para vídeo/audio puede configurar opcionalmente una tasa de bits; para vídeo también puede ajustar ancho × alto.
  5. Elija la ubicación de salida (se sugiere automáticamente un nombre de archivo) y presione Convertir.
  6. El trabajo aparece en la parte inferior (Trabajos) con una barra de progreso en vivo.

9. Guía de descarga

  1. Vaya a la pestaña Descargar.
  2. Pegue la URL del vídeo o de la música.
  3. Elija el Modo: Vídeo o Música (MP3).
  4. Elija la Calidad del vídeo: Mejor, 2160p, 1440p, 1080p, 720p, 480p. Para MP3 se usa automáticamente la mejor pista de audio.
  5. Opcionalmente, cambie la carpeta de descarga (de forma predeterminada, su carpeta Downloads).
  6. Presione Descargar. El resultado se nombra Título [id].mp4 o Título [id].mp3.
Consejo: si FFmpeg no está instalado, las descargas de vídeo recurren a archivos de flujo único (el vídeo puede no tener sonido o usar un contenedor menos común). Instale FFmpeg desde la pestaña Herramientas para obtener archivos MP4 fusionados y limpios.

10. Panel de trabajos

  • Cada operación (convertir, descargar, instalar) se ejecuta en segundo plano como un trabajo.
  • Los trabajos se enumeran en la parte inferior de la ventana con el porcentaje de progreso y un breve mensaje de estado.
  • Al tener éxito se muestra la ruta del archivo generado; el botón abre la carpeta / selecciona el archivo en el administrador de archivos.

11. Solución de problemas

  • «yt-dlp not found» / error de descarga → instale yt-dlp desde la pestaña Herramientas.
  • El vídeo descargado no tiene sonido o un contenedor extraño → instale FFmpeg para que los flujos se fusionen.
  • DOCX → PDF no produce nada → instale LibreOffice.
  • PDF → imagen/texto no produce nada → instale poppler.
  • La descarga se detiene / el progreso se congela → la plataforma puede estar bloqueando yt-dlp o la conexión; actualice yt-dlp (reinstálelo desde Herramientas) e inténtelo de nuevo.
  • Falla la instalación de la herramienta → compruebe la conectividad a Internet / proxy / firewall; la descarga proviene de GitHub Releases o johnvansickle.com.

12. Compilación desde el código fuente

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux necesita primero los paquetes de desarrollo WebKit2GTK/GTK3:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev inicia la aplicación en modo de desarrollo con recarga en caliente. El comando regenera frontend/dist y frontend/wailsjs automáticamente. Se proporciona una canalización de CI para Linux (AMD64 + ARM64) en .github/workflows.
