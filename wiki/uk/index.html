1. Огляд

SyntaxOrigin Multi Tools — це настільна програма для конвертування файлів (відео, аудіо, зображення, Office та PDF) і завантаження медіа з тисяч платформ, вбрана у швидке нативне вікно. Вона створена на фреймворку Wails: інтерфейс користувача — це звичайна HTML/CSS/JS-сторінка, а вся складна робота (FFmpeg, yt-dlp, LibreOffice, poppler) виконується у Go-бекенді. Програма підтримує 21 мову і працює на Windows та Linux.

2. Можливості

  • Конвертуйте файли відео, аудіо, зображення та документів між форматами.
  • Завантажуйте відео або MP3-музику з платформ, підтримуваних yt-dlp.
  • Встановлення в один клік FFmpeg і yt-dlp; автоматичне виявлення LibreOffice і poppler.
  • 21 мова: автоматично береться з операційної системи, перемикається у будь-який момент, з RTL-макетом для арабської, урду та перської.
  • Живий список завдань зі смугами прогресу та покроковими повідомленнями про статус.
  • Жодних зовнішніх бібліотек інтерфейсу — швидкий, темний настільний інтерфейс.

5. Встановлення (Windows / Linux)

  1. Завантажте бінарний файл для вашої платформи та запустіть його (див. файли релізу), або зберіть його самостійно — див. Збірка з вихідного коду.
  2. Під час першого запуску програма автоматично вибирає мову операційної системи. Якщо її не вдається визначити, використовується англійська.
  3. Відкрийте вкладку Інструменти. Інструменти, позначені як відсутні, показують кнопку Встановити. Спочатку встановіть FFmpeg і yt-dlp.
  4. Ви готові конвертувати та завантажувати.
Windows: оскільки стандартна збірка не підписана, SmartScreen може попередити про «невідомого видавця». Оберіть Додаткові відомості → Усе одно виконати. Деякі антивірусні/проксі-програми можуть блокувати завантаження бінарних файлів; додайте виняток для програми та її папки bin.

6. Вибір мови

  • Під час запуску автоматично використовується мова операційної системи (за замовчуванням: англійська).
  • Селектор мови розташований у верхньому правому куті вікна. Вибір мови миттєво перекладає весь інтерфейс (зокрема запущені завдання).
  • Ваш ручний вибір запам'ятовується і має пріоритет під час наступного запуску.
  • Арабська, урду та перська автоматично використовують макет справа-наліво.

8. Посібник із конвертації

  1. Перейдіть на вкладку Конвертувати.
  2. Виберіть Тип (відео / аудіо / зображення / документ).
  3. Натисніть Вибрати вхідний файл і виберіть файл (підтримувані формати відфільтровуються автоматично).
  4. Виберіть цільовий формат. Для відео/аудіо можна додатково встановити бітрейт; для відео також можна масштабувати ширину × висоту.
  5. Виберіть місце збереження (ім'я файлу пропонується автоматично) і натисніть Конвертувати.
  6. Завдання з'явиться внизу (Завдання) з живою смугою прогресу.

9. Посібник із завантаження

  1. Перейдіть на вкладку Завантажити.
  2. Вставте URL відео/музики.
  3. Виберіть Режим: Відео або Музика (MP3).
  4. Виберіть Якість для відео: Best, 2160p, 1440p, 1080p, 720p, 480p. Для MP3 автоматично використовується найкращий аудіопотік.
  5. За бажанням змініть папку завантаження (за замовчуванням — ваша папка Downloads).
  6. Натисніть Завантажити. Вихідний файл отримує назву Title [id].mp4 або Title [id].mp3.
Порада: якщо FFmpeg не встановлено, завантаження відео переходять на файли single-stream (відео може бути без звуку або використовувати менш поширений контейнер). Встановіть FFmpeg з вкладки Інструменти для чистих об'єднаних MP4-файлів.

10. Панель завдань

  • Кожна операція (конвертація, завантаження, встановлення) виконується у фоновому режимі як завдання.
  • Завдання перелічуються внизу вікна з відсотком прогресу та коротким повідомленням про статус.
  • У разі успіху показується шлях до створеного файлу; кнопка відкриває папку / виділяє файл у файловому менеджері.

11. Усунення неполадок

  • «yt-dlp не знайдено» / помилка завантаження → встановіть yt-dlp з вкладки Інструменти.
  • Завантажене відео без звуку або з незвичним контейнером → встановіть FFmpeg, щоб потоки об'єднувалися.
  • DOCX → PDF нічого не створює → встановіть LibreOffice.
  • PDF → зображення/текст нічого не створює → встановіть poppler.
  • Завантаження зависає / прогрес заморожено → платформа може блокувати yt-dlp або з'єднання; оновіть yt-dlp (перевстановіть з Інструментів) і спробуйте знову.
  • Встановлення інструмента не вдається → перевірте інтернет-з'єднання / проксі / брандмауер; завантаження надходить з GitHub Releases або johnvansickle.com.

12. Збірка з вихідного коду

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Для Linux спочатку потрібні пакунки розробника WebKit2GTK/GTK3:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev запускає програму в режимі розробки з гарячим перезавантаженням. Команда автоматично перестворює frontend/dist і frontend/wailsjs. Конвеєр CI для Linux (AMD64 + ARM64) надається у .github/workflows.

  • Go — мова програмування
  • GitHub Actions — CI-збірки для Linux
