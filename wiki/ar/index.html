1. نظرة عامة

SyntaxOrigin Multi Tools هو تطبيق سطح مكتب لـ تحويل الملفات (فيديو، صوت، صور، أوفيس وPDF) و تنزيل الوسائط من آلاف المنصات، داخل نافذة أصلية سريعة. تم بناؤه باستخدام إطار عمل Wails: واجهة المستخدم عبارة عن صفحة HTML/CSS/JS عادية، بينما تعمل جميع المهام الثقيلة (FFmpeg وyt-dlp وLibreOffice وpoppler) في الخلفية بلغة Go. يدعم 21 لغة ويعمل على Windows و Linux.

2. الميزات

  • تحويل ملفات الفيديو والصوت والصور والمستندات بين الصيغ.
  • تنزيل فيديو أو موسيقى MP3 من المنصات المدعومة بواسطة yt-dlp.
  • تثبيت بنقرة واحدة لـ FFmpeg وyt-dlp؛ مع الاكتشاف التلقائي لـ LibreOffice وpoppler.
  • 21 لغة: تُؤخذ تلقائيًا من نظام التشغيل، ويمكن تبديلها في أي وقت، مع تخطيط من اليمين إلى اليسار (RTL) للعربية والأردية والفارسية.
  • قائمة مهام مباشرة (Jobs) مع أشرطة تقدّم ورسائل حالة خطوة بخطوة.
  • بدون مكتبات واجهة خارجية — واجهة سطح مكتب داكنة وسريعة.

5. التثبيت (Windows / Linux)

  1. نزّل الملف التنفيذي (binary) المناسب لمنصتك وشغّله (انظر ملفات الإصدارات)، أو ابنِه بنفسك — راجع البناء من المصدر.
  2. عند أول تشغيل، يختار التطبيق لغة نظام التشغيل تلقائيًا. إذا تعذّر اكتشافها، يرجع إلى الإنجليزية.
  3. افتح تبويب Tools. الأدوات غير المتوفرة تُظهر زر Install (تثبيت). ثبّت FFmpeg وyt-dlp أولًا.
  4. أنت الآن جاهز للتحويل والتنزيل.
Windows: نظرًا لأن البناء الافتراضي غير موقّع، فقد يحذّر SmartScreen بشأن «ناشر غير معروف». اختر مزيد من المعلومات ← التشغيل على أي حال (More info → Run anyway). قد تحجب بعض أدوات مكافحة الفيروسات/البروكسي تنزيل الملفات التنفيذية؛ أضف استثناءً للتطبيق ومجلد bin الخاص به.

6. اختيار اللغة

  • عند بدء التشغيل تُستخدم لغة نظام التشغيل تلقائيًا (الاحتياط: الإنجليزية).
  • محدِّد اللغة موجود في أعلى يمين النافذة. اختيار لغة ما يترجم الواجهة بالكامل فورًا (بما في ذلك المهام قيد التشغيل).
  • يتم تذكُّر اختيارك اليدوي ويحظى بالأولوية عند التشغيل التالي.
  • تستخدم العربية والأردية والفارسية تخطيطًا من اليمين إلى اليسار تلقائيًا.

8. دليل التحويل

  1. انتقل إلى تبويب Convert (تحويل).
  2. اختر النوع (فيديو / صوت / صورة / مستند).
  3. انقر على اختيار الإدخال (Select input) واختر الملف (يتم تصفية الصيغ المدعومة تلقائيًا).
  4. اختر صيغة الهدف. يمكنك اختياريًا ضبط معدل البت (bitrate) للفيديو/الصوت؛ وبالنسبة للفيديو يمكنك أيضًا تغيير العرض × الارتفاع.
  5. اختر موقع المخرجات (يُقترح اسم ملف تلقائيًا) واضغط Convert (تحويل).
  6. تظهر المهمة في الأسفل (Jobs) مع شريط تقدّم مباشر.

9. دليل التنزيل

  1. انتقل إلى تبويب Download (تنزيل).
  2. الصق URL الخاص بالفيديو/الموسيقى.
  3. اختر الوضع: فيديو أو موسيقى (MP3).
  4. اختر الجودة للفيديو: الأفضل، 2160p، 1440p، 1080p، 720p، 480p. بالنسبة لـ MP3 يُستخدم أفضل مسار صوتي تلقائيًا.
  5. بإمكانك اختياريًا تغيير مجلد التنزيل (الافتراضي هو مجلد Downloads لديك).
  6. اضغط Download (تنزيل). يُسمى المخرج Title [id].mp4 أو Title [id].mp3.
نصيحة: إذا لم يكن FFmpeg مثبتًا، فستنخفض عمليات تنزيل الفيديو إلى ملفات أحادية المسار (single-stream) (قد يفتقر الفيديو إلى الصوت أو يستخدم حاوية أقل شيوعًا). ثبّت FFmpeg من تبويب Tools للحصول على ملفات MP4 مدمجة نظيفة.

10. لوحة Jobs

  • كل عملية (تحويل، تنزيل، تثبيت) تُنفَّذ في الخلفية كـ job (مهمة).
  • تُدرج المهام في أسفل النافذة مع نسبة التقدم ورسالة حالة مختصرة.
  • عند النجاح يُعرض مسار الملف المُنتج؛ يفتح الزر المجلد / يحدد الملف في مدير الملفات.

11. استكشاف الأخطاء وإصلاحها

  • «yt-dlp غير موجود» / خطأ تنزيل ← ثبّت yt-dlp من تبويب Tools.
  • الفيديو الذي تم تنزيله بلا صوت أو بحاوية غريبة ← ثبّت FFmpeg حتى يتم دمج المسارات.
  • تحويل DOCX ← PDF لا يُنتج شيئًا ← ثبّت LibreOffice.
  • تحويل PDF ← صورة/نص لا يُنتج شيئًا ← ثبّت poppler.
  • التنزيل يتوقف / يتجمد التقدم ← قد تكون المنصة تحجب yt-dlp أو الاتصال؛ حدّث yt-dlp (أعد تثبيته من Tools) وحاول مجددًا.
  • فشل تثبيت الأداة ← تحقق من اتصال الإنترنت / البروكسي / جدار الحماية؛ يأتي التنزيل من GitHub Releases أو johnvansickle.com.

12. البناء من المصدر

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

يتطلب Linux أولًا حزم تطوير WebKit2GTK/GTK3:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev يشغّل التطبيق في وضع التطوير بإعادة التحميل السريع (hot-reload). يعيد الأمر توليد frontend/dist وfrontend/wailsjs تلقائيًا. يتم توفير خط أنابيب CI للينكس (AMD64 + ARM64) تحت .github/workflows.
