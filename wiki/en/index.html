1. Overview

SyntaxOrigin Multi Tools is a desktop application for converting files (video, audio, image, office and PDF) and downloading media from thousands of platforms, wrapped in a fast native window. It is built with the Wails framework: the user interface is a regular HTML/CSS/JS page, while all heavy work (FFmpeg, yt-dlp, LibreOffice, poppler) runs in a Go backend. It supports 21 languages and works on Windows and Linux.

2. Features

  • Convert video, audio, image and document files between formats.
  • Download video or MP3 music from platforms supported by yt-dlp.
  • One-click install of FFmpeg and yt-dlp; automatic detection of LibreOffice and poppler.
  • 21 languages: automatically taken from the operating system, switchable at any time, with the RTL layout for Arabic, Urdu and Persian.
  • Live job list with progress bars and step-by-step status messages.
  • No external frontend libraries — a fast, dark desktop UI.

5. Installation (Windows / Linux)

  1. Download the binary for your platform and run it (see the release files), or build it yourself — see Building from source.
  2. On first launch, the app selects the operating-system language automatically. If it cannot detect one, it falls back to English.
  3. Open the Tools tab. Tools marked as missing show an Install button. Install FFmpeg and yt-dlp first.
  4. You are ready to convert and download.
Windows: because the default build is unsigned, SmartScreen may warn about an “unknown publisher”. Choose More info → Run anyway. Some antivirus/proxy tools can block binary downloads; add an exception for the app and its bin folder.

6. Language selection

  • On startup the language of the operating system is used automatically (fallback: English).
  • The language selector is in the top-right of the window. Choosing a language immediately translates the whole interface (including running jobs).
  • Your manual choice is remembered and has priority on the next launch.
  • Arabic, Urdu and Persian use a right-to-left layout automatically.

8. Conversion guide

  1. Go to the Convert tab.
  2. Choose the Kind (Video / Audio / Image / Document).
  3. Click Select input and pick the file (supported formats are filtered automatically).
  4. Choose the target format. For video/audio you can optionally set a bitrate; for video you can also scale width × height.
  5. Choose the output location (a filename is suggested automatically) and press Convert.
  6. The job appears at the bottom (Jobs) with a live progress bar.

9. Download guide

  1. Go to the Download tab.
  2. Paste the video/music URL.
  3. Choose Mode: Video or Music (MP3).
  4. Choose Quality for video: Best, 2160p, 1440p, 1080p, 720p, 480p. For MP3 the best audio stream is used automatically.
  5. Optionally change the download folder (defaults to your Downloads folder).
  6. Press Download. Output is named Title [id].mp4 or Title [id].mp3.
Tip: if FFmpeg is not installed, video downloads fall back to single-stream files (video may lack sound or use a less common container). Install FFmpeg from the Tools tab for clean merged MP4 files.

10. Jobs panel

  • Every operation (convert, download, install) runs in the background as a job.
  • Jobs are listed at the bottom of the window with progress percentage and a short status message.
  • On success the produced file path is shown; button opens the folder / selects the file in the file manager.

11. Troubleshooting

  • “yt-dlp not found” / download error → install yt-dlp from the Tools tab.
  • Downloaded video has no sound or a strange container → install FFmpeg so streams are merged.
  • DOCX → PDF produces nothing → install LibreOffice.
  • PDF → image/text produces nothing → install poppler.
  • Download stalls / progress frozen → the platform may be blocking yt-dlp or the connection; update yt-dlp (reinstall from Tools) and try again.
  • Tool instalation fails → check internet connectivity / proxy / firewall; the download comes from GitHub Releases or johnvansickle.com.

12. Building from source

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux first needs WebKit2GTK/GTK3 development packages:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev launches the app in hot-reload development mode. The command regenerates frontend/dist and frontend/wailsjs automatically. A Linux CI pipeline (AMD64 + ARM64) is provided under .github/workflows.
