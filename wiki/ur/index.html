1. جائزہ

SyntaxOrigin Multi Tools ایک ڈیسک ٹاپ ایپلیکیشن ہے جو فائلوں کی تبدیلی (ویڈیو، آڈیو، تصویر، آفس اور PDF) اور ہزاروں پلیٹ فارمز سے میڈیا ڈاؤن لوڈ کرنے کے لیے ہے، جو ایک تیز مقامی (native) ونڈو میں پیش کی جاتی ہے۔ یہ Wails فریم ورک کے ساتھ بنائی گئی ہے: صارف انٹرفیس ایک عام HTML/CSS/JS صفحہ ہے، جب کہ تمام بھاری کام (FFmpeg, yt-dlp, LibreOffice, poppler) Go بیک اینڈ میں چلتا ہے۔ یہ 21 زبانیں سپورٹ کرتی ہے اور Windows اور Linux پر کام کرتی ہے۔

2. خصوصیات

  • ویڈیو، آڈیو، تصویر اور دستاویز فائلوں کو ایک فارمیٹ سے دوسرے فارمیٹ میں تبدیل کریں۔
  • yt-dlp کے تعاون یافتہ پلیٹ فارمز سے ویڈیو یا MP3 موسیقی ڈاؤن لوڈ کریں۔
  • FFmpeg اور yt-dlp کی ایک کلک تنصیب؛ LibreOffice اور poppler کا خودکار پتہ لگانا۔
  • 21 زبانیں: خود بخود آپریٹنگ سسٹم سے منتخب ہوتی ہیں، کسی بھی وقت تبدیل کی جا سکتی ہیں، عربی، اردو اور فارسی کے لیے RTL ترتیب کے ساتھ۔
  • پیش رفت بار اور مرحلہ وار اسٹیٹس پیغامات کے ساتھ لائیو جوہب لسٹ (Jobs)۔
  • کوئی بیرونی فرنٹ اینڈ لائبریریاں نہیں — ایک تیز، ڈارک ڈیسک ٹاپ UI۔

5. تنصیب (Windows / Linux)

  1. اپنے پلیٹ فارم کے لیے بائنری ڈاؤن لوڈ کر کے چلائیں (ریلیز فائلیں دیکھیں)، یا خود اسے بنائیں — سورس سے بنانا دیکھیں۔
  2. پہلی بار لانچ پر، ایپ خود بخود آپریٹنگ سسٹم کی زبان منتخب کرتی ہے۔ اگر یہ پتہ نہ لگا سکے تو انگریزی پر واپس آ جاتی ہے۔
  3. Tools ٹیب کھولیں۔ جو ٹولز غیر موجود ہیں، ان پر Install (انسٹال) کا بٹن ظاہر ہوتا ہے۔ پہلے FFmpeg اور yt-dlp انسٹال کریں۔
  4. اب آپ تبدیل اور ڈاؤن لوڈ کرنے کے لیے تیار ہیں۔
Windows: چونکہ ڈیفالٹ بلڈ دستخط شدہ نہیں ہوتا، SmartScreen «نامعلوم پبلشر» کی ہدایت دے سکتا ہے۔ مزید معلومات → پھر بھی چلائیں (More info → Run anyway) کا انتخاب کریں۔ کچھ اینٹی وائرس/پراکسی ٹولز بائنری ڈاؤن لوڈ کو بلاک کر سکتے ہیں؛ ایپ اور اس کے bin فولڈر کے لیے استثنا شامل کریں۔

6. زبان کا انتخاب

  • اسٹارٹ اپ پر آپریٹنگ سسٹم کی زبان خود بخود استعمال ہوتی ہے (اگر نہ ملے تو انگریزی)۔
  • زبان کا سلیکٹر ونڈو کے اوپر دائیں جانب ہوتا ہے۔ کوئی زبان منتخب کرنے پر پورا انٹرفیس فوراً ترجمہ ہو جاتا ہے (چل رہے جوہبز سمیت)۔
  • آپ کا دستی انتخاب یاد رکھا جاتا ہے اور اگلی بار لانچ پر اسے ترجیح ملتی ہے۔
  • عربی، اردو اور فارسی خود بخود دائیں سے بائیں (RTL) ترتیب استعمال کرتی ہیں۔

7. Tools ٹیب

ٹولایپ میں انسٹال ہو سکتا ہےنوٹس
FFmpegہاںWindows: BtbN GPL بلڈ؛ Linux: johnvansickle اسٹیٹک بلڈ (تقریباً 120 MB)
yt-dlpہاںآپ کے پلیٹ فارم کے مطابق بائنری ڈاؤن لوڈ ہوتی ہے
LibreOfficeنہیںlibreoffice.org سے انسٹال کریں
popplerنہیںpoppler.freedesktop.org سے انسٹال کریں

فائلیں فی صارف کنفیگ فولڈر میں SyntaxOrigin Multi Tools\bin کے نیچے محفوظ ہوتی ہیں (Windows: %APPDATA%؛ Linux: $XDG_CONFIG_HOME یا ~/.config)۔

8. تبدیل کرنے کا گائیڈ

  1. Convert (تبدیل کریں) ٹیب پر جائیں۔
  2. قسم (ویڈیو / آڈیو / تصویر / دستاویز) منتخب کریں۔
  3. ان پٹ منتخب کریں (Select input) پر کلک کریں اور فائل منتخب کریں (تعاون یافتہ فارمیٹس خود بخود فلٹر ہو جاتے ہیں)۔
  4. ہدف فارمیٹ منتخب کریں۔ ویڈیو/آڈیو کے لیے آپ اختیاری طور پر بٹ ریٹ سیٹ کر سکتے ہیں؛ ویڈیو کے لیے آپ چوڑائی × اونچائی بھی بدل سکتے ہیں۔
  5. آؤٹ پٹ مقام منتخب کریں (فائل نام خود بخود تجویز ہوتا ہے) اور Convert (تبدیل کریں) دبائیں۔
  6. جوہب نیچے (Jobs) میں لائیو پیش رفت بار کے ساتھ ظاہر ہوتا ہے۔

9. ڈاؤن لوڈ گائیڈ

  1. Download (ڈاؤن لوڈ) ٹیب پر جائیں۔
  2. ویڈیو/موسیقی کا URL پیسٹ کریں۔
  3. موڈ منتخب کریں: ویڈیو یا موسیقی (MP3)۔
  4. ویڈیو کے لیے کوالٹی منتخب کریں: بہترین، 2160p، 1440p، 1080p، 720p، 480p۔ MP3 کے لیے بہترین آڈیو اسٹریم خود بخود استعمال ہوتی ہے۔
  5. اختیاری طور پر ڈاؤن لوڈ فولڈر تبدیل کریں (ڈیفالٹ آپ کے Downloads فولڈر میں ہوتا ہے)۔
  6. Download (ڈاؤن لوڈ) دبائیں۔ آؤٹ پٹ کا نام Title [id].mp4 یا Title [id].mp3 ہوتا ہے۔
ٹپ: اگر FFmpeg نصب نہ ہو تو ویڈیو ڈاؤن لوڈز سنگل-اسٹریم فائلوں پر گر جاتے ہیں (ویڈیو میں آواز نہیں ہو سکتی یا کم عام کنٹینر استعمال ہو سکتا ہے)۔ صاف مرج شدہ MP4 فائلوں کے لیے Tools ٹیب سے FFmpeg انسٹال کریں۔

10. Jobs پینل

  • ہر آپریشن (تبدیل، ڈاؤن لوڈ، انسٹال) پس منظر میں ایک job (جوہب) کے طور پر چلتا ہے۔
  • جوہبز ونڈو کے نیچے پیش رفت فیصد اور مختصر اسٹیٹس پیغام کے ساتھ درج ہوتے ہیں۔
  • کامیابی پر تیار کردہ فائل کا پاتھ دکھایا جاتا ہے؛ بٹن فولڈر کھولتا ہے / فائل مینیجر میں فائل منتخب کرتا ہے۔

11. مسائل کا حل

  • «yt-dlp نہیں ملا» / ڈاؤن لوڈ کی خرابی → Tools ٹیب سے yt-dlp انسٹال کریں۔
  • ڈاؤن لوڈ شدہ ویڈیو میں آواز نہیں یا عجیب کنٹینر ہے → FFmpeg انسٹال کریں تاکہ اسٹریمز مرج ہو جائیں۔
  • DOCX → PDF سے کچھ نہیں بنتا → LibreOffice انسٹال کریں۔
  • PDF → تصویر/متن سے کچھ نہیں بنتا → poppler انسٹال کریں۔
  • ڈاؤن لوڈ رک جاتا ہے / پیش رفت جم جاتی ہے → ممکن ہے پلیٹ فارم yt-dlp یا کنکشن کو بلاک کر رہا ہو؛ yt-dlp کو اپڈیٹ کریں (Tools سے دوبارہ انسٹال کریں) اور دوبارہ کوشش کریں۔
  • ٹول کی تنصیب ناکام ہوتی ہے → انٹرنیٹ کنکشن / پراکسی / فائر وال چیک کریں؛ ڈاؤن لوڈ GitHub Releases یا johnvansickle.com سے آتا ہے۔

12. سورس سے بنانا

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux کو پہلے WebKit2GTK/GTK3 ڈویلپمنٹ پیکجز درکار ہوتے ہیں:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev ایپ کو ہاٹ-ریلوڈ ڈویلپمنٹ موڈ میں لانچ کرتا ہے۔ یہ کمانڈ frontend/dist اور frontend/wailsjs کو خود بخود دوبارہ تیار کرتی ہے۔ .github/workflows میں ایک Linux CI پائپ لائن (AMD64 + ARM64) فراہم کی گئی ہے۔

13. پروجیکٹ کا ڈھانچہ

├── app.go                 # Wails bindings: jobs, convert, download, dialogs
├── i18n.go                # Backend strings + system-language detection
├── main.go                # App entry point (wails.Run)
├── internal/
│   ├── converter/         # audio, video, image, document converters
│   ├── toolkit/           # download, binary lookup, ffmpeg helpers
│   ├── tools/             # tool detection + one-click installers
│   └── ytdlp/             # yt-dlp wrapper (progress parsing, formats)
├── frontend/
│   └── src/               # vanilla-JS UI (index.html, app.js, i18n.js, style.css)
├── wails.json
├── README.md
└── wiki/<language>/       # this documentation (HTML)
