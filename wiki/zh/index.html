1. 概述

SyntaxOrigin Multi Tools 是一款桌面应用程序，用于 转换文件（视频、音频、图片、办公文档和 PDF）以及 从数以千计的平台下载媒体，所有功能都封装在快速的原生窗口中。它基于 Wails 框架构建：用户界面 是一个普通的 HTML/CSS/JS 页面，而所有繁重的工作（FFmpeg、yt-dlp、 LibreOffice、poppler）都在 Go 后端运行。它支持 21 种 语言，可在 Windows 和 Linux 上运行。

2. 功能特性

  • 在不同格式之间转换视频、音频、图片和文档文件。
  • 从 yt-dlp 支持的平台上下载视频或 MP3 音乐。
  • FFmpeg 和 yt-dlp 一键安装；自动检测 LibreOffice 和 poppler。
  • 21 种语言：自动采用操作系统的语言，可随时切换，并针对阿拉伯语、乌尔都语和波斯语提供从右到左（RTL）布局。
  • 实时任务列表，带进度条和分步状态消息。
  • 无外部前端库 — 快速、深色的桌面界面。

5. 安装（Windows / Linux）

  1. 下载适合您平台的二进制文件并运行它（参阅发布文件），或者自行构建 — 请参阅从源代码构建。
  2. 首次启动时，应用会自动选择操作系统的语言。如果无法检测到，则回退到英语。
  3. 打开工具标签页。标记为缺失的工具会显示安装按钮。请先安装FFmpeg和yt-dlp。
  4. 现在您可以开始转换和下载了。
Windows：由于默认构建未签名，SmartScreen 可能会警告“发布者未知”的消息。请选择更多信息 → 仍要运行。某些防病毒/代理工具可能会阻止二进制文件下载；请为应用及其bin文件夹添加例外。

6. 语言选择

  • 启动时自动使用操作系统的语言（回退：英语）。
  • 语言选择器位于窗口右上角。选择一种语言会立即翻译整个界面（包括正在运行的任务）。
  • 您手动选择的语言会被记住，并在下次启动时优先使用。
  • 阿拉伯语、乌尔都语和波斯语会自动使用从右到左的布局。

7. 工具标签页

工具是否可在应用内安装说明

8. 转换指南

  1. 转到转换标签页。
  2. 选择类型（视频 / 音频 / 图片 / 文档）。
  3. 点击选择输入文件并选择文件（支持的格式会自动过滤）。
  4. 选择目标格式。对于视频/音频，您可以可选地设置比特率；对于视频，您还可以调整宽度 × 高度。
  5. 选择输出位置（会自动建议文件名），然后按下转换。
  6. 任务会出现在底部（任务），并带有实时进度条。

9. 下载指南

  1. 转到下载标签页。
  2. 粘贴视频/音乐的URL。
  3. 选择模式：视频或音乐（MP3）。
  4. 为视频选择质量：最佳、2160p、1440p、1080p、720p、480p。对于 MP3，会自动使用最佳的音频流。
  5. 可选地更改下载文件夹（默认为您的Downloads文件夹）。
  6. 按下下载。输出文件名为 Title [id].mp4 或 Title [id].mp3。
提示：如果未安装 FFmpeg，视频下载会回退为单流文件（视频可能没有声音或使用不常见的容器格式）。请从工具标签页安装 FFmpeg，以获得干净的合并 MP4 文件。

10. 任务面板

  • 每个操作（转换、下载、安装）都会在后台作为任务运行。
  • 任务会列在窗口底部，并带有进度百分比和简短的状态消息。
  • 成功后显示生成的文件路径；按钮会在文件管理器中打开文件夹 / 选中文件。

11. 故障排除

  • "yt-dlp 未找到" / 下载错误 → 从工具标签页安装yt-dlp。
  • 下载的视频没有声音或容器格式奇怪 → 安装FFmpeg，以便合并流。
  • DOCX → PDF 没有产生任何结果 → 安装LibreOffice。
  • PDF → 图片/文本没有产生任何结果 → 安装poppler。
  • 下载停滞 / 进度冻结 → 平台可能在阻止 yt-dlp 或连接；更新 yt-dlp（从工具中重新安装）并重试。
  • 工具安装失败 → 检查网络连接 / 代理 / 防火墙；下载来自 GitHub Releases 或 johnvansickle.com。

12. 从源代码构建

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux 首先需要安装 WebKit2GTK/GTK3 开发包：

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev 会以热重载开发模式启动应用。该命令会自动重新生成 frontend/dist 和 frontend/wailsjs。在 .github/workflows 下提供了 Linux CI 流水线（AMD64 + ARM64）。
