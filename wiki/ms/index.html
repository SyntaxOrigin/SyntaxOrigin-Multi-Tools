1. Gambaran keseluruhan

SyntaxOrigin Multi Tools ialah aplikasi desktop untuk menukar fail (video, audio, imej, dokumen dan PDF) dan memuat turun media daripada beribu-ribu platform, dibungkus dalam tetingkap asli yang pantas. Aplikasi ini dibina dengan rangka kerja Wails: antara muka pengguna ialah halaman HTML/CSS/JS biasa, manakala semua kerja berat (FFmpeg, yt-dlp, LibreOffice, poppler) dijalankan dalam backend Go. Ia menyokong 21 bahasa dan berfungsi pada Windows dan Linux.

2. Ciri-ciri

  • Menukar fail video, audio, imej dan dokumen antara format.
  • Memuat turun video atau muzik MP3 daripada platform yang disokong oleh yt-dlp.
  • Pemasangan satu klik FFmpeg dan yt-dlp; pengesanan automatik LibreOffice dan poppler.
  • 21 bahasa: diambil secara automatik daripada sistem pengendalian, boleh ditukar pada bila-bila masa, dengan susun atur RTL untuk bahasa Arab, Urdu dan Parsi.
  • Senarai tugasan langsung dengan bar kemajuan dan mesej status langkah demi langkah.
  • Tiada pustaka antara muka luaran — UI desktop gelap yang pantas.

5. Pemasangan (Windows / Linux)

  1. Muat turun fail binari untuk platform anda dan jalankannya (lihat fail keluaran), atau bina sendiri — lihat Membina daripada sumber.
  2. Pada pelancaran pertama, aplikasi memilih bahasa sistem pengendalian secara automatik. Jika tidak dapat dikesan, ia kembali kepada bahasa Inggeris.
  3. Buka tab Alat. Alat yang ditandakan sebagai tiada menunjukkan butang Pasang. Pasang FFmpeg dan yt-dlp terlebih dahulu.
  4. Anda bersedia untuk menukar dan memuat turun.
Windows: kerana binaan lalai tidak ditandatangani, SmartScreen mungkin memberi amaran tentang "penerbit tidak diketahui". Pilih Maklumat lanjut → Jalankan juga. Sesetengah perisian antivirus/proksi boleh menyekat muat turun binari; tambah pengecualian untuk aplikasi dan folder binnya.

6. Pemilihan bahasa

  • Semasa permulaan, bahasa sistem pengendalian digunakan secara automatik (lalai: bahasa Inggeris).
  • Pemilih bahasa terletak di penjuru kanan atas tetingkap. Memilih bahasa serta-merta menterjemah keseluruhan antara muka (termasuk tugasan yang sedang berjalan).
  • Pilihan manual anda diingati dan diberi keutamaan pada pelancaran seterusnya.
  • Bahasa Arab, Urdu dan Parsi menggunakan susun atur dari kanan ke kiri secara automatik.

8. Panduan penukaran

  1. Pergi ke tab Tukar.
  2. Pilih Jenis (Video / Audio / Imej / Dokumen).
  3. Klik Pilih input dan pilih fail (format yang disokong ditapis secara automatik).
  4. Pilih format sasaran. Untuk video/audio, anda boleh menetapkan bitrate secara pilihan; untuk video, anda juga boleh menskalakan lebar × tinggi.
  5. Pilih lokasi output (nama fail dicadangkan secara automatik) dan tekan Tukar.
  6. Tugasan muncul di bahagian bawah (Tugasan) dengan bar kemajuan langsung.

9. Panduan muat turun

  1. Pergi ke tab Muat Turun.
  2. Tampal URL video/muzik.
  3. Pilih Mod: Video atau Muzik (MP3).
  4. Pilih Kualiti untuk video: Terbaik, 2160p, 1440p, 1080p, 720p, 480p. Untuk MP3, strim audio terbaik digunakan secara automatik.
  5. Secara pilihan, ubah folder muat turun (lalai: folder Downloads anda).
  6. Tekan Muat Turun. Output dinamakan Title [id].mp4 atau Title [id].mp3.
Petua: jika FFmpeg tidak dipasang, muat turun video menggunakan fail satustrim (video mungkin tiada bunyi atau menggunakan bekas yang kurang biasa). Pasang FFmpeg daripada tab Alat untuk mendapatkan fail MP4 gabungan yang bersih.

10. Panel tugasan

  • Setiap operasi (tukar, muat turun, pasang) berjalan di latar belakang sebagai tugasan.
  • Tugasan disenaraikan di bahagian bawah tetingkap dengan peratus kemajuan dan mesej status ringkas.
  • Apabila berjaya, laluan fail yang dihasilkan dipaparkan; butang membuka folder / memilih fail dalam pengurus fail.

11. Penyelesaian masalah

  • "yt-dlp tidak ditemui" / ralat muat turun → pasang yt-dlp daripada tab Alat.
  • Video yang dimuat turun tiada bunyi atau bekas pelik → pasang FFmpeg supaya strim digabungkan.
  • DOCX → PDF tidak menghasilkan apa-apa → pasang LibreOffice.
  • PDF → imej/teks tidak menghasilkan apa-apa → pasang poppler.
  • Muat turun terhenti / kemajuan membeku → platform mungkin menyekat yt-dlp atau sambungan; kemas kini yt-dlp (pasang semula daripada Alat) dan cuba lagi.
  • Pemasangan alat gagal → semak sambungan internet / proksi / tembok api; muat turun datang daripada GitHub Releases atau johnvansickle.com.

12. Membina daripada sumber

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux memerlukan pakej pembangunan WebKit2GTK/GTK3 terlebih dahulu:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev melancarkan aplikasi dalam mod pembangunan muat semula panas. Perintah itu menjana semula frontend/dist dan frontend/wailsjs secara automatik. Saluran paip CI Linux (AMD64 + ARM64) disediakan di bawah .github/workflows.

13. Struktur projek
