1. Visão geral

SyntaxOrigin Multi Tools é um aplicativo de desktop para converter arquivos (vídeo, áudio, imagem, documentos do Office e PDF) e baixar mídia de milhares de plataformas, em uma janela nativa rápida. Ele é construído com o framework Wails: a interface do usuário é uma página HTML/CSS/JS comum, enquanto todo o trabalho pesado (FFmpeg, yt-dlp, LibreOffice, poppler) é executado em um backend em Go. Suporta 21 idiomas e funciona no Windows e no Linux.

2. Recursos

  • Converta arquivos de vídeo, áudio, imagem e documento entre formatos.
  • Baixe vídeos ou música MP3 de plataformas compatíveis com yt-dlp.
  • Instalação com um clique do FFmpeg e do yt-dlp; detecção automática do LibreOffice e do poppler.
  • 21 idiomas: obtido automaticamente do sistema operacional, alterável a qualquer momento, com layout RTL para árabe, urdu e persa.
  • Lista de tarefas ao vivo com barras de progresso e mensagens de status passo a passo.
  • Sem bibliotecas de frontend externas — uma interface de desktop escura e rápida.

5. Instalação (Windows / Linux)

  1. Baixe o binário para sua plataforma e execute-o (veja os arquivos da versão), ou compile você mesmo — consulte Compilação a partir do código-fonte.
  2. No primeiro início, o aplicativo seleciona automaticamente o idioma do sistema operacional. Se não conseguir detectar um, ele volta para o inglês.
  3. Abra a aba Ferramentas. As ferramentas marcadas como ausentes mostram um botão Instalar. Instale primeiro o FFmpeg e o yt-dlp.
  4. Você está pronto para converter e baixar.
Windows: como a versão padrão não é assinada, o SmartScreen pode avisar sobre um “editor desconhecido”. Escolha Mais informações → Executar mesmo assim. Algumas ferramentas de antivírus/proxy podem bloquear downloads de binários; adicione uma exceção para o aplicativo e sua pasta bin.

6. Seleção de idioma

  • Na inicialização, o idioma do sistema operacional é usado automaticamente (padrão: inglês).
  • O seletor de idioma fica no canto superior direito da janela. Escolher um idioma traduz imediatamente toda a interface (incluindo as tarefas em execução).
  • Sua escolha manual é lembrada e tem prioridade na próxima inicialização.
  • O árabe, o urdu e o persa usam um layout da direita para a esquerda automaticamente.

8. Guia de conversão

  1. Vá para a aba Converter.
  2. Escolha o Tipo (Vídeo / Áudio / Imagem / Documento).
  3. Clique em Selecionar entrada e escolha o arquivo (os formatos compatíveis são filtrados automaticamente).
  4. Escolha o formato de destino. Para vídeo/áudio, você pode definir opcionalmente um bitrate; para vídeo, também pode redimensionar largura × altura.
  5. Escolha o local de saída (um nome de arquivo é sugerido automaticamente) e pressione Converter.
  6. A tarefa aparece na parte inferior (Tarefas) com uma barra de progresso ao vivo.

9. Guia de download

  1. Vá para a aba Baixar.
  2. Cole a URL do vídeo/música.
  3. Escolha o Modo: Vídeo ou Música (MP3).
  4. Escolha a Qualidade para vídeo: Melhor, 2160p, 1440p, 1080p, 720p, 480p. Para MP3, o melhor fluxo de áudio é usado automaticamente.
  5. Opcionalmente, altere a pasta de download (o padrão é sua pasta Downloads).
  6. Pressione Baixar. A saída é nomeada Título [id].mp4 ou Título [id].mp3.
Dica: se o FFmpeg não estiver instalado, os downloads de vídeo passam a usar arquivos de fluxo único (o vídeo pode ficar sem som ou usar um contêiner menos comum). Instale o FFmpeg na aba Ferramentas para obter arquivos MP4 mesclados e limpos.

10. Painel de tarefas

  • Cada operação (converter, baixar, instalar) é executada em segundo plano como uma tarefa.
  • As tarefas são listadas na parte inferior da janela com porcentagem de progresso e uma breve mensagem de status.
  • Em caso de sucesso, o caminho do arquivo de saída é mostrado; o botão abre a pasta / seleciona o arquivo no gerenciador de arquivos.

11. Solução de problemas

  • “yt-dlp not found” / erro de download → instale o yt-dlp na aba Ferramentas.
  • O vídeo baixado não tem som ou tem um contêiner estranho → instale o FFmpeg para que os fluxos sejam mesclados.
  • DOCX → PDF não produz nada → instale o LibreOffice.
  • PDF → imagem/texto não produz nada → instale o poppler.
  • Download parado / progresso congelado → a plataforma pode estar bloqueando o yt-dlp ou a conexão; atualize o yt-dlp (reinstale em Ferramentas) e tente novamente.
  • A instalação da ferramenta falha → verifique a conectividade com a internet / proxy / firewall; o download vem do GitHub Releases ou do johnvansickle.com.

12. Compilação a partir do código-fonte

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

O Linux precisa primeiro dos pacotes de desenvolvimento WebKit2GTK/GTK3:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev inicia o aplicativo em modo de desenvolvimento com recarga a quente. O comando regenera frontend/dist e frontend/wailsjs automaticamente. Um pipeline de CI Linux (AMD64 + ARM64) é fornecido em .github/workflows.
