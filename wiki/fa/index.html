1. نمای کلی

SyntaxOrigin Multi Tools یک برنامه دسکتاپ برای تبدیل فایل‌ها (ویدئو، صدا، تصویر، آفیس و PDF) و دانلود رسانه از هزاران پلتفرم است که در یک پنجره بومی و سریع ارائه می‌شود. این برنامه با فریم‌ورک Wails ساخته شده است: رابط کاربری یک صفحه معمولی HTML/CSS/JS است، در حالی که تمام کارهای سنگین (FFmpeg, yt-dlp, LibreOffice, poppler) در بک‌اند Go اجرا می‌شود. این برنامه از 21 زبان پشتیبانی می‌کند و روی Windows و Linux کار می‌کند.

2. ویژگی‌ها

  • تبدیل فایل‌های ویدئو، صدا، تصویر و سند بین فرمت‌های مختلف.
  • دانلود ویدئو یا موسیقی MP3 از پلتفرم‌های پشتیبانی‌شده توسط yt-dlp.
  • نصب با یک کلیک برای FFmpeg و yt-dlp؛ شناسایی خودکار LibreOffice و poppler.
  • 21 زبان: به‌طور خودکار از سیستم‌عامل گرفته می‌شود، در هر زمان قابل تغییر است، با چیدمان راست‌به‌چپ (RTL) برای عربی، اردو و فارسی.
  • لیست زنده کارها (Jobs) با نوارهای پیشرفت و پیام‌های وضعیت مرحله‌به‌مرحله.
  • بدون کتابخانه‌های خارجی فرانت‌اند — یک رابط کاربری دسکتاپ سریع و تیره.

5. نصب (Windows / Linux)

  1. فایل باینری مخصوص پلتفرم خود را دانلود و اجرا کنید (فایل‌های انتشار را ببینید)، یا خودتان آن را بسازید — به ساخت از سورس مراجعه کنید.
  2. در اولین اجرا، برنامه به‌طور خودکار زبان سیستم‌عامل را انتخاب می‌کند. اگر نتواند آن را شناسایی کند، به انگلیسی برمی‌گردد.
  3. برگه Tools را باز کنید. ابزارهایی که ناموجود هستند، دکمه Install (نصب) را نشان می‌دهند. ابتدا FFmpeg و yt-dlp را نصب کنید.
  4. حالا آماده تبدیل و دانلود هستید.
Windows: از آنجا که نسخه پیش‌فرض امضا نشده است، SmartScreen ممکن است درباره «ناشر ناشناس» هشدار دهد. گزینه اطلاعات بیشتر → همچنان اجرا کنید (More info → Run anyway) را انتخاب کنید. برخی ابزارهای آنتی‌ویروس/پروکسی می‌توانند دانلود فایل‌های باینری را مسدود کنند؛ برای برنامه و پوشه bin آن استثنا اضافه کنید.

6. انتخاب زبان

  • در هنگام راه‌اندازی، به‌طور خودکار از زبان سیستم‌عامل استفاده می‌شود (در صورت نبود، انگلیسی).
  • انتخابگر زبان در بالا-راست پنجره قرار دارد. انتخاب یک زبان، کل رابط کاربری را فوراً ترجمه می‌کند (از جمله کارهای در حال اجرا).
  • انتخاب دستی شما به خاطر سپرده می‌شود و در اجرای بعدی اولویت دارد.
  • عربی، اردو و فارسی به‌طور خودکار از چیدمان راست‌به‌چپ استفاده می‌کنند.

7. برگه Tools

فایل‌ها در پوشه پیکربندی مخصوص هر کاربر، در SyntaxOrigin Multi Tools\bin ذخیره می‌شوند (Windows: %APPDATA%؛ Linux: $XDG_CONFIG_HOME یا ~/.config).

8. راهنمای تبدیل

  1. به برگه Convert (تبدیل) بروید.
  2. نوع (ویدئو / صدا / تصویر / سند) را انتخاب کنید.
  3. روی انتخاب ورودی (Select input) کلیک کنید و فایل را انتخاب کنید (فرمت‌های پشتیبانی‌شده به‌طور خودکار فیلتر می‌شوند).
  4. فرمت هدف را انتخاب کنید. برای ویدئو/صدا می‌توانید به‌صورت اختیاری نرخ بیت (bitrate) را تنظیم کنید؛ برای ویدئو می‌توانید عرض × ارتفاع را نیز تغییر دهید.
  5. محل خروجی را انتخاب کنید (نام فایل به‌طور خودکار پیشنهاد می‌شود) و Convert (تبدیل) را بزنید.
  6. کار در پایین (Jobs) با نوار پیشرفت زنده ظاهر می‌شود.

9. راهنمای دانلود

  1. به برگه Download (دانلود) بروید.
  2. URL ویدئو/موسیقی را جای‌گذاری کنید.
  3. حالت را انتخاب کنید: ویدئو یا موسیقی (MP3).
  4. برای ویدئو کیفیت را انتخاب کنید: بهترین، 2160p، 1440p، 1080p، 720p، 480p. برای MP3 بهترین استریم صوتی به‌طور خودکار استفاده می‌شود.
  5. به‌صورت اختیاری پوشه دانلود را تغییر دهید (به‌صورت پیش‌فرض از پوشه Downloads شما استفاده می‌کند).
  6. Download (دانلود) را بزنید. خروجی با نام Title [id].mp4 یا Title [id].mp3 ذخیره می‌شود.
نکته: اگر FFmpeg نصب نباشد، دانلودهای ویدئو به فایل‌های تک‌استریم (single-stream) تبدیل می‌شوند (ویدئو ممکن است صدا نداشته باشد یا از کانتینر کمتر رایجی استفاده کند). برای دریافت فایل‌های MP4 ادغام‌شده و تمیز، FFmpeg را از برگه Tools نصب کنید.

10. پنل Jobs

  • هر عملیات (تبدیل، دانلود، نصب) در پس‌زمینه به‌صورت یک job (کار) اجرا می‌شود.
  • کارها در پایین پنجره با درصد پیشرفت و یک پیام وضعیت کوتاه فهرست می‌شوند.
  • در صورت موفقیت، مسیر فایل تولیدشده نمایش داده می‌شود؛ دکمه پوشه را باز می‌کند / فایل را در فایل‌منیجر انتخاب می‌کند.

11. عیب‌یابی

  • «yt-dlp پیدا نشد» / خطای دانلود → yt-dlp را از برگه Tools نصب کنید.
  • ویدئوی دانلودشده صدا ندارد یا کانتینر عجیبی دارد → FFmpeg را نصب کنید تا استریم‌ها ادغام شوند.
  • تبدیل DOCX → PDF نتیجه‌ای ندارد → LibreOffice را نصب کنید.
  • تبدیل PDF → تصویر/متن نتیجه‌ای ندارد → poppler را نصب کنید.
  • دانلود متوقف می‌شود / پیشرفت قفل می‌ماند → احتمالاً پلتفرم yt-dlp یا اتصال را مسدود کرده است؛ yt-dlp را به‌روزرسانی کنید (از Tools دوباره نصب کنید) و دوباره تلاش کنید.
  • نصب ابزار ناموفق است → اتصال اینترنت / پروکسی / فایروال را بررسی کنید؛ دانلود از GitHub Releases یا johnvansickle.com انجام می‌شود.

12. ساخت از سورس

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux ابتدا به بسته‌های توسعه WebKit2GTK/GTK3 نیاز دارد:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev برنامه را در حالت توسعه با بارگذاری مجدد خودکار (hot-reload) اجرا می‌کند. این دستور frontend/dist و frontend/wailsjs را به‌طور خودکار بازتولید می‌کند. یک پایپ‌لاین CI لینوکس (AMD64 + ARM64) در .github/workflows ارائه شده است.
