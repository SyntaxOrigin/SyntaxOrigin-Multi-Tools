1. 概要

SyntaxOrigin Multi Tools は、ファイル変換（動画・音声・画像・オフィス・PDF）と 数千のプラットフォームからのメディアダウンロードを行うデスクトップアプリケーションで、 高速なネイティブウィンドウにまとめられています。Wails フレームワークで構築されており、 ユーザーインターフェースは通常の HTML/CSS/JS ページで、重い処理（FFmpeg、yt-dlp、 LibreOffice、poppler）はすべて Go バックエンドで実行されます。21 の 言語に対応し、Windows と Linux で動作します。

2. 機能

  • 動画・音声・画像・ドキュメントファイルを各種フォーマット間で変換します。
  • yt-dlp が対応するプラットフォームから動画や MP3 音楽をダウンロードします。
  • FFmpeg と yt-dlp のワンクリックインストール。LibreOffice と poppler は自動検出されます。
  • 21 の言語：OS の言語設定を自動的に採用し、いつでも切り替え可能。アラビア語・ウルドゥー語・ペルシア語には RTL レイアウトを使用します。
  • プログレスバーと段階ごとのステータスメッセージを備えたライブジョブリスト。
  • 外部フロントエンドライブラリは不要 — 高速でダークなデスクトップ UI。

3. 対応フォーマット

種類入力出力
動画mp4, mkv, avi, mov, webmmp4, mkv, avi, mov, webm
音声mp3, wav, flac, aac, oggmp3, wav, flac, aac, ogg
画像png, jpg (jpeg), webp, bmppng, jpg, webp, bmp

注意：ドキュメント変換（PDF ↔ DOCX、PDF → 画像/テキスト）には、システムに LibreOffice や poppler がインストールされている必要があります。これらは自動検出されますが、アプリに同梱されていません — ツールタブを参照してください。

4. 必要条件

実行時に必要なツール

ツール用途
FFmpegすべての動画/音声/画像変換。最高品質でマージされたダウンロード
yt-dlpプラットフォームからの動画/音楽ダウンロード

FFmpeg と yt-dlp はアプリケーションの内部からワンクリックでインストールできます。LibreOffice と poppler はユーザー自身でインストールする必要があります（リンクはツールタブに表示されます）。

5. インストール（Windows / Linux）

  1. お使いのプラットフォーム用のバイナリをダウンロードして実行するか（リリースファイルを参照）、またはご自身でビルドします — ソースからのビルドを参照してください。
  2. 初回起動時に、アプリは OS の言語を自動的に選択します。検出できない場合は英語にフォールバックします。
  3. ツールタブを開きます。不足しているツールにはインストールボタンが表示されます。最初にFFmpegとyt-dlpをインストールしてください。
  4. これで変換とダウンロードの準備が整いました。
Windows：既定のビルドは署名されていないため、SmartScreen が「公開元が不明」という警告を表示する場合があります。詳細情報 → 実行を選択してください。一部のウイルス対策ソフトやプロキシツールがバイナリのダウンロードをブロックする場合があります。アプリとそのbinフォルダに例外を追加してください。

6. 言語の選択

  • 起動時には OS の言語が自動的に使用されます（フォールバック：英語）。
  • 言語セレクターはウィンドウの右上にあります。言語を選択すると、インターフェース全体（実行中のジョブを含む）がすぐに翻訳されます。
  • 手動で選択した言語は記憶され、次回の起動時に優先されます。
  • アラビア語・ウルドゥー語・ペルシア語は、右から左へのレイアウトが自動的に適用されます。

7. ツールタブ

ツールアプリ内でインストール可能備考
FFmpegはいWindows：BtbN GPL ビルド。Linux：johnvansickle の静的ビルド（約120 MB）
yt-dlpはいお使いのプラットフォームに一致するバイナリがダウンロードされます
LibreOfficeいいえlibreoffice.org からインストール
popplerいいえpoppler.freedesktop.org からインストール

ファイルはユーザーごとの設定フォルダにある SyntaxOrigin Multi Tools\bin に保存されます（Windows：%APPDATA%。Linux：$XDG_CONFIG_HOME または ~/.config）。

8. 変換ガイド

  1. 変換タブに移動します。
  2. 種類（動画 / 音声 / 画像 / ドキュメント）を選択します。
  3. 入力ファイルを選択をクリックしてファイルを選びます（対応フォーマットは自動的にフィルタリングされます）。
  4. 変換先フォーマットを選択します。動画/音声では必要に応じてビットレートを設定でき、動画では幅 × 高さも変更できます。
  5. 出力先を選択し（ファイル名は自動的に提案されます）、変換を押します。
  6. ジョブは下部（ジョブ）にリアルタイムのプログレスバー付きで表示されます。

9. ダウンロードガイド

  1. ダウンロードタブに移動します。
  2. 動画/音楽のURLを貼り付けます。
  3. モードを選択します：動画または音楽（MP3）。
  4. 動画の画質を選択します：最高、2160p、1440p、1080p、720p、480p。MP3 の場合は、最高の音声ストリームが自動的に使用されます。
  5. 必要に応じてダウンロードフォルダを変更します（既定ではDownloadsフォルダ）。
  6. ダウンロードを押します。出力は Title [id].mp4 または Title [id].mp3 という名前になります。
ヒント：FFmpeg がインストールされていない場合、動画ダウンロードは単一ストリームのファイルにフォールバックします（音声がないか、あまり一般的でないコンテナになる場合があります）。きれいにマージされた MP4 ファイルを得るには、ツールタブから FFmpeg をインストールしてください。

10. ジョブパネル

  • すべての操作（変換、ダウンロード、インストール）はジョブとしてバックグラウンドで実行されます。
  • ジョブはウィンドウの下部に、進捗率と短いステータスメッセージ付きで一覧表示されます。
  • 成功すると生成されたファイルのパスが表示されます。ボタンを押すと、フォルダを開いたり、ファイルマネージャーでファイルを選択したりできます。

11. トラブルシューティング

  • 「yt-dlp not found」/ ダウンロードエラー → ツールタブからyt-dlpをインストールします。
  • ダウンロードした動画に音声がない、または奇妙なコンテナ形式 → FFmpegをインストールしてストリームをマージします。
  • DOCX → PDF で何も出力されない → LibreOfficeをインストールします。
  • PDF → 画像/テキストで何も出力されない → popplerをインストールします。
  • ダウンロードが停滞 / 進行状況が止まる → プラットフォームが yt-dlp や接続をブロックしている可能性があります。yt-dlp を更新し（ツールから再インストール）、再試行してください。
  • ツールのインストールに失敗する → インターネット接続 / プロキシ / ファイアウォールを確認してください。ダウンロードは GitHub Releases または johnvansickle.com から行われます。

12. ソースからのビルド

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux では最初に WebKit2GTK/GTK3 開発パッケージが必要です：

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev はホットリロード開発モードでアプリを起動します。このコマンドは frontend/dist と frontend/wailsjs を自動的に再生成します。.github/workflows の下に Linux CI パイプライン（AMD64 + ARM64）が用意されています。

│   ├── toolkit/           # download, binary lookup, ffmpeg helpers
│   ├── tools/             # tool detection + one-click installers
│   └── ytdlp/             # yt-dlp wrapper (progress parsing, formats)
├── frontend/
│   └── src/               # vanilla-JS UI (index.html, app.js, i18n.js, style.css)
├── wails.json
├── README.md
└── wiki/<language>/       # this documentation (HTML)
