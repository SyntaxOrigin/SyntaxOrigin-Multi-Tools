1. Обзор

SyntaxOrigin Multi Tools — это настольное приложение для конвертации файлов (видео, аудио, изображения, офисные документы и PDF) и загрузки медиа с тысяч платформ, оформленное в виде быстрого нативного окна. Оно создано на основе фреймворка Wails: пользовательский интерфейс представляет собой обычную HTML/CSS/JS-страницу, а вся ресурсоёмкая работа (FFmpeg, yt-dlp, LibreOffice, poppler) выполняется в бэкенде на Go. Приложение поддерживает 21 язык и работает на Windows и Linux.

2. Возможности

  • Конвертация файлов видео, аудио, изображений и документов между форматами.
  • Загрузка видео или MP3-музыки с платформ, поддерживаемых yt-dlp.
  • Установка в один клик FFmpeg и yt-dlp; автоматическое обнаружение LibreOffice и poppler.
  • 21 язык: язык берётся автоматически из операционной системы и его можно переключить в любой момент; для арабского, урду и персидского используется макет справа налево.
  • Живой список задач с индикаторами выполнения и пошаговыми сообщениями о статусе.
  • Без внешних библиотек интерфейса — быстрый тёмный интерфейс рабочего стола.

5. Установка (Windows / Linux)

  1. Скачайте двоичный файл для своей платформы и запустите его (см. файлы релиза), или соберите приложение самостоятельно — см. «Сборка из исходного кода».
  2. При первом запуске приложение автоматически выбирает язык операционной системы. Если определить его не удаётся, используется английский язык.
  3. Откройте вкладку «Инструменты». Для инструментов, помеченных как отсутствующие, отображается кнопка «Установить». Сначала установите FFmpeg и yt-dlp.
  4. Можно приступать к конвертации и загрузке.
Windows: поскольку обычная сборка не подписана, SmartScreen может предупредить о «неизвестном издателе». Выберите Дополнительно → Всё равно выполнить. Некоторые антивирусные программы и прокси могут блокировать загрузку двоичных файлов; добавьте исключение для приложения и его папки bin.

6. Выбор языка

  • При запуске автоматически используется язык операционной системы (по умолчанию — английский).
  • Селектор языка находится в правом верхнем углу окна. Выбор языка немедленно переводит весь интерфейс (включая выполняющиеся задачи).
  • Ваш ручной выбор запоминается и имеет приоритет при следующем запуске.
  • Для арабского, урду и персидского автоматически используется макет справа налево.

8. Руководство по конвертации

  1. Перейдите на вкладку «Конвертация».
  2. Выберите вид (Видео / Аудио / Изображение / Документ).
  3. Нажмите «Выбрать файл» и выберите файл (поддерживаемые форматы фильтруются автоматически).
  4. Выберите целевой формат. Для видео/аудио можно дополнительно задать битрейт; для видео также можно изменить ширину × высоту.
  5. Выберите место сохранения (имя файла предлагается автоматически) и нажмите «Конвертировать».
  6. Задача появится в нижней части окна («Задачи») с индикатором выполнения в реальном времени.

9. Руководство по загрузке

  1. Перейдите на вкладку «Загрузка».
  2. Вставьте URL видео/музыки.
  3. Выберите режим: Видео или Музыка (MP3).
  4. Выберите качество для видео: Лучшее, 2160p, 1440p, 1080p, 720p, 480p. Для MP3 автоматически используется лучший аудиопоток.
  5. При желании измените папку загрузки (по умолчанию используется ваша папка Downloads).
  6. Нажмите «Загрузить». Файлу присваивается имя Title [id].mp4 или Title [id].mp3.
Совет: если FFmpeg не установлен, видеозагрузка переключается на однопотоковые файлы (видео может быть без звука или в менее распространённом контейнере). Установите FFmpeg на вкладке «Инструменты», чтобы получать чистые объединённые MP4-файлы.

10. Панель задач

  • Каждая операция (конвертация, загрузка, установка) выполняется в фоне как задача.
  • Задачи отображаются в нижней части окна с процентом выполнения и кратким сообщением о статусе.
  • В случае успеха показывается путь к созданному файлу; кнопка открывает папку / выделяет файл в файловом менеджере.

11. Устранение неполадок

  • «yt-dlp не найден» / ошибка загрузки → установите yt-dlp на вкладке «Инструменты».
  • В скачанном видео нет звука или необычный контейнер → установите FFmpeg, чтобы потоки объединялись.
  • DOCX → PDF ничего не создаёт → установите LibreOffice.
  • PDF → изображение/текст ничего не создаёт → установите poppler.
  • Загрузка зависает / прогресс застывает → возможно, платформа блокирует yt-dlp или соединение; обновите yt-dlp (переустановите через «Инструменты») и попробуйте снова.
  • Не удаётся установить инструмент → проверьте подключение к интернету / прокси / брандмауэр; загрузка выполняется с GitHub Releases или johnvansickle.com.

12. Сборка из исходного кода

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Для Linux сначала потребуются пакеты разработки WebKit2GTK/GTK3:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev запускает приложение в режиме разработки с «горячей» перезагрузкой. Команда автоматически пересоздаёт frontend/dist и frontend/wailsjs. Конвейер CI для Linux (AMD64 + ARM64) предоставлен в каталоге .github/workflows.
