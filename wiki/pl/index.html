1. Przegląd

SyntaxOrigin Multi Tools to aplikacja komputerowa do konwertowania plików (wideo, audio, obraz, dokumenty Office i PDF) oraz pobierania multimediów z tysięcy platform, zamknięta w szybkim, natywnym oknie. Została zbudowana z użyciem frameworku Wails: interfejs użytkownika to zwykła strona HTML/CSS/JS, a całe ciężkie przetwarzanie (FFmpeg, yt-dlp, LibreOffice, poppler) odbywa się w backendzie Go. Aplikacja obsługuje 21 języków i działa na Windows oraz Linux.

2. Funkcje

  • Konwertuj pliki wideo, audio, obraz i dokument między formatami.
  • Pobieraj filmy i muzykę MP3 z platform obsługiwanych przez yt-dlp.
  • Instalacja jednym kliknięciem FFmpeg i yt-dlp; automatyczne wykrywanie LibreOffice i poppler.
  • 21 języków: automatycznie pobrany z systemu operacyjnego, przełączany w dowolnym momencie, z układem RTL dla arabskiego, urdu i perskiego.
  • Lista zadań na żywo z paskami postępu i komunikatami o statusie krok po kroku.
  • Brak zewnętrznych bibliotek frontendowych — szybki, ciemny interfejs desktopowy.

5. Instalacja (Windows / Linux)

  1. Pobierz plik binarny dla swojej platformy i uruchom go (zobacz pliki wydania), albo zbuduj go samodzielnie — zobacz Budowanie z kodu źródłowego.
  2. Przy pierwszym uruchomieniu aplikacja automatycznie wybiera język systemu operacyjnego. Jeśli nie może go wykryć, przechodzi na angielski.
  3. Otwórz zakładkę Narzędzia. Narzędzia oznaczone jako brakujące pokazują przycisk Zainstaluj. Najpierw zainstaluj FFmpeg i yt-dlp.
  4. Możesz już konwertować i pobierać.
Windows: ponieważ domyślna kompilacja nie jest podpisana, SmartScreen może ostrzegać o „nieznanym wydawcy". Wybierz Więcej informacji → Uruchom mimo to. Niektóre programy antywirusowe/proxy mogą blokować pobieranie plików binarnych; dodaj wyjątek dla aplikacji i jej folderu bin.

6. Wybór języka

  • Podczas uruchamiania automatycznie używany jest język systemu operacyjnego (domyślnie: angielski).
  • Selektor języka znajduje się w prawym górnym rogu okna. Wybór języka natychmiast tłumaczy cały interfejs (w tym działające zadania).
  • Twój ręczny wybór jest zapamiętywany i ma priorytet przy następnym uruchomieniu.
  • Języki arabski, urdu i perski automatycznie używają układu od prawej do lewej.

8. Przewodnik konwersji

  1. Przejdź na zakładkę Konwertuj.
  2. Wybierz Rodzaj (wideo / audio / obraz / dokument).
  3. Kliknij Wybierz wejście i wskaż plik (obsługiwane formaty są filtrowane automatycznie).
  4. Wybierz format docelowy. Dla wideo/audio możesz opcjonalnie ustawić bitrate; dla wideo możesz również skalować szerokość × wysokość.
  5. Wybierz lokalizację wyjściową (nazwa pliku jest proponowana automatycznie) i naciśnij Konwertuj.
  6. Zadanie pojawia się na dole (Zadania) z paskiem postępu na żywo.

9. Przewodnik pobierania

  1. Przejdź na zakładkę Pobierz.
  2. Wklej URL filmu/muzyki.
  3. Wybierz Tryb: Wideo lub Muzyka (MP3).
  4. Wybierz Jakość dla wideo: Best, 2160p, 1440p, 1080p, 720p, 480p. Dla MP3 automatycznie używany jest najlepszy strumień audio.
  5. Opcjonalnie zmień folder pobierania (domyślnie folder Downloads).
  6. Naciśnij Pobierz. Plik wyjściowy nosi nazwę Title [id].mp4 lub Title [id].mp3.
Wskazówka: jeśli FFmpeg nie jest zainstalowany, pobieranie wideo przechodzi na pliki single-stream (wideo może nie mieć dźwięku lub używać mniej popularnego kontenera). Zainstaluj FFmpeg z zakładki Narzędzia, aby uzyskać czyste, scalone pliki MP4.

10. Panel zadań

  • Każda operacja (konwersja, pobieranie, instalacja) działa w tle jako zadanie.
  • Zadania są wyświetlane na dole okna z procentem postępu i krótkim komunikatem o statusie.
  • Po powodzeniu wyświetlana jest ścieżka utworzonego pliku; przycisk otwiera folder / zaznacza plik w menedżerze plików.

11. Rozwiązywanie problemów

  • „Nie znaleziono yt-dlp" / błąd pobierania → zainstaluj yt-dlp z zakładki Narzędzia.
  • Pobrane wideo bez dźwięku lub z dziwnym kontenerem → zainstaluj FFmpeg, aby strumienie zostały scalone.
  • DOCX → PDF nic nie generuje → zainstaluj LibreOffice.
  • PDF → obraz/tekst nic nie generuje → zainstaluj poppler.
  • Pobieranie się zacina / zamrożony postęp → platforma może blokować yt-dlp lub połączenie; zaktualizuj yt-dlp (zainstaluj ponownie z Narzędzi) i spróbuj ponownie.
  • Instalacja narzędzia nie powiodła się → sprawdź połączenie internetowe / proxy / zaporę; plik pochodzi z GitHub Releases lub johnvansickle.com.

12. Budowanie z kodu źródłowego

go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd SyntaxOrigin-Multi-Tools
wails build        # binary → build/bin/

Linux najpierw wymaga pakietów deweloperskich WebKit2GTK/GTK3:

sudo apt-get install -y libgtk-3-dev libwebkit2gtk-4.1-dev

wails dev uruchamia aplikację w trybie deweloperskim z hot-reload. Polecenie automatycznie generuje frontend/dist i frontend/wailsjs. Pipeline CI dla Linuksa (AMD64 + ARM64) jest dostarczony w .github/workflows.

13. Struktura projektu

├── app.go                 # Wails bindings: jobs, convert, download, dialogs

├── internal/
│   ├── converter/         # audio, video, image, document converters
│   ├── toolkit/           # download, binary lookup, ffmpeg helpers
│   ├── tools/             # tool detection + one-click installers
│   └── ytdlp/             # yt-dlp wrapper (progress parsing, formats)
├── frontend/
│   └── src/               # vanilla-JS UI (index.html, app.js, i18n.js, style.css)
├── wails.json
├── README.md
└── wiki/<language>/       # this documentation (HTML)
